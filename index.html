Bài tập: 3 Cách nhúng CSS vào trang HTML

1. Inline Style (Tiêu đề màu đỏ)

Đoạn văn này được định dạng bằng Inline CSS sử dụng thuộc tính style trực tiếp trên thẻ.

2. Internal Style (Tiêu đề màu xanh dương)

Đoạn văn này được định dạng bằng Internal CSS nằm trong thẻ <style> ở phần <head>.

3. External Style (Tiêu đề màu xanh lá cây)

Đoạn văn này được định dạng bằng External CSS từ tệp style.css riêng biệt liên kết qua thẻ <link>.
